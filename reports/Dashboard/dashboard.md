# Automobile Sales & Profit Dashboard

This repository contains an interactive dashboard analyzing **Automobile Sales, Discounts, Revenue, and Profit Trends** for different brands.  
The dashboard helps visualize how each brand performs across **years, units sold, and profitability**.

## 🚗 Features

- **Units Sold**: Shows total units sold per brand.  
- **Discounts**: Visualizes average discounts offered.  
- **Sales by Year**: Year-wise sales trend line.  
- **Profit vs Revenue**: Bar + line comparison of revenue vs profit across years.  
- **Brand Selection**: Sidebar with logos for brand-specific filtering.  
- **Car Model Details**: Displays available models for the selected brand.  

---

## ⚙️ Tech Stack

- **Power BI** (for dashboard creation & visuals)  
- **Python (Pandas, Matplotlib, Plotly)** (for preprocessing & forecasting)  
- **Excel/CSV datasets** (raw sales + production data)
